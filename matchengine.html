MatchEngine

A multi-threaded, low-latency order matching engine engineered for microsecond execution and fault tolerance.

C++ Low-Latency Systems Multithreading TCP Sockets Backend Architecture

Statistics

  • Started June 2026
  • Status Stable
  • GitHub Repo

Description

Background

Financial trading platforms require systems capable of processing thousands of orders per second with absolute precision. To push my systems engineering skills, I built a backend order matching engine designed to pair "buy" and "sell" network requests over TCP sockets with microsecond latency.

Solution

The solution bypasses slow database queries by maintaining a highly optimized in-memory Order Book using custom STL data structures. It actively throttles I/O rendering to decouple the core matching logic from terminal bottlenecks, ensuring maximum throughput.

Core Features

The engine's performance relies entirely on optimized execution structures:

  • Algorithmic Efficiency: Engineered in Modern C++ utilizing std::unordered_map and doubly linked lists (std::list) to achieve strictly O(1) time complexity for order lookups and cancellations.
  • Binary Disaster Recovery: Implemented a background thread using zero-cost memory serialization to dump active system state directly to disk, enabling instant restoration after server crashes.
  • Microsecond Profiling: Instrumented core matching loops with std::chrono to calculate and output P50, P90, and P99 latency percentiles under heavy concurrent network loads.

Learning Outcomes

This project bridged the gap between theoretical data structures and high-performance systems architecture. It provided hands-on experience with thread synchronization, memory management, and identifying real-world bottlenecks like terminal I/O.
